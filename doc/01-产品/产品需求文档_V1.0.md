## 一、项目概述

### 1.1 业务背景

公司核心业务涵盖政府专项债咨询、展馆博物馆EPC总承包、信息化智能化项目三大板块。项目制运营模式下，每个项目涉及投标、立项、设计、采购、施工/实施、验收、结算等多个阶段，跨部门协作频繁，信息流转链条长、知识复用率低。当前依赖传统办公工具和人工协调，存在信息孤岛、经验流失、效率低下等痛点。

此外，国内工程项目实施须严格遵循**招投标法**、**政府采购法**、**建设工程质量管理条例**等法律法规，各阶段均有对应的标准化管控要求（财评、过控、监理、审计等），流程合规性要求极高。现有工具无法覆盖从招投标到竣工审计的全链路合规管理，导致关键节点依赖人工核查，风险敞口大。

### 1.2 产品定位

构建一个 **AI原生** 的项目内部协作平台，融合 monday.com 级别的工作管理能力与国内项目标准化流程管理，核心差异在于：

- **对话即操作**：员工通过与专业Agent对话完成日常工作，而非在复杂菜单中寻找功能按钮
- **越用越聪明**：平台持续学习企业知识、项目经验和个人工作习惯，形成不断进化的组织智能
- **工作流自适应**：工作流引擎具备AI推理能力，能根据项目类型、阶段和异常情况动态调整流程
- **中国化适配**：采用国产大模型（DeepSeek等），内置国内工程管理全流程（招投标→财评→过控→监理→审计），满足数据合规与本地化要求
- **功能性操作并行**：在对话式交互之上，提供 monday.com 风格的看板、表格、甘特图、仪表盘等多视图操作界面，满足习惯传统项目管理工具的用户

### 1.3 核心目标

| 目标维度 | 具体指标 | 量化基准 |
|---------|---------|---------|
| 信息同步 | 项目相关信息在5分钟内触达所有相关人员 | 消息延迟 < 5min |
| 任务协同 | 任务分配、流转、追踪全链路AI辅助 | 人工协调成本减少 50%+ |
| 知识沉淀 | 项目文档、经验、教训自动归档入库 | 知识复用率提升 60%+ |
| 决策效率 | 关键审批节点AI预审+风险提示 | 审批周期缩短 30%+ |
| 流程合规 | 国内项目标准化流程100%线上化 | 合规偏差率 < 2% |
| 管理可视 | 管理层一屏掌握全项目群态势 | 决策响应时间缩短 40%+ |

├──────────────────────────────────────────────────────────┤
│                 Agent 调度层（Orchestration）               │
│     意图识别 ｜ Agent路由 ｜ 多Agent协同 ｜ 会话管理          │
├──────────────────────────────────────────────────────────┤
│                 Agent 能力层（Agent Skills）                │
│  项目管理｜财务｜法务｜采购｜人事｜投标｜文档｜知识｜过控｜监理  │
├──────────────────────────────────────────────────────────┤

├──────────────────────────────────────────────────────────┤

| 架构层 | 核心组件 | 职责说明 |
|-------|---------|---------|
| 交互层 | 对话式UI、可交互卡片、多视图工作台、鸟瞰可视化、移动端 | 用户与系统的唯一触点，提供多模态交互体验 |
| Agent调度层 | 意图识别、Agent路由、多Agent协同、会话管理 | 理解用户意图，将任务路由到合适的专业Agent |
| Agent能力层 | 项目管理、财务、法务、采购、人事、投标、文档、知识、过控、监理Agent | 各领域专业Agent提供具体业务能力 |
| 核心引擎层 | 知识库引擎、工作流引擎、权限引擎、学习引擎、可视化引擎 | 支撑平台运行的基础能力组件 |
| 数据与集成层 | 项目数据、文档存储、外部对接、向量数据库、审计日志 | 数据持久化、外部系统集成、全链路审计 |

## 三、多Agent体系设计

### 3.1 Agent角色矩阵

平台采用"1个通用调度Agent + N个专业Agent"的架构。通用调度Agent作为前台接收员工所有对话，理解意图后路由到专业Agent，或协调多Agent联合完成复杂任务。

| Agent名称 | 职责领域 | 核心能力 |
|-----------|---------|---------|
| **项目管理Agent** | 项目全周期 | 进度追踪、里程碑管理、风险预警、资源调度建议、WBS分解 |
| **财务Agent** | 财务管理 | 费用报销审核、预算对比分析、资金计划提醒、发票校验、财评协助 |
| **法务Agent** | 合同法务 | 合同条款审查、风险条款标注、合规性检查、招标文件法律审查 |
| **采购Agent** | 采购管理 | 供应商匹配推荐、比价分析、采购流程跟踪、政府采购合规校验 |
| **人事Agent** | 人力资源 | 考勤统计、绩效数据汇总、招聘进度追踪、政策答疑 |
| **投标Agent** | 投标管理 | 招标信息监控、标书框架生成、历史中标分析、资质匹配、评标模拟 |
| **文档Agent** | 文档处理 | 文档生成/模板填充、格式转换、版本管理、智能摘要 |
| **知识Agent** | 知识管理 | 经验检索、案例推荐、标准规范查询、新员工培训引导 |
| **过控Agent** | 过程控制 | 四控管理（进度/质量/安全/成本）、偏差预警、纠偏建议、变更管理 |
| **审计Agent** | 审计监督 | 跟踪审计辅助、造价核查、合规审计清单、审计底稿生成 |

### 3.2 多Agent协作机制

**串行协作**：任务按顺序在多个Agent之间流转。例如采购申请流程：采购Agent → 财务Agent → 项目管理Agent 依次审核，每个环节的输出作为下一环节的输入。

**并行协作**：多个Agent同时工作，结果由调度Agent汇总。例如项目立项评估：法务Agent、财务Agent、采购Agent、项目管理Agent 同时输出评估意见，最终生成综合评估报告。

**人机协同**：Agent完成初步工作后，@真人员工确认或补充，确保关键决策由人做出。所有涉及金额确认、合同签署、审批放行等操作必须经过人工确认。

**联动预警**：当过控Agent检测到进度/质量/安全/成本异常时，自动联动对应Agent链进行分析和处理建议，形成闭环处理机制。

### 3.3 Agent学习与进化机制

- **反馈闭环**：员工对Agent输出"采纳/修改/拒绝"均记录，用于优化Agent后续表现
- **知识注入**：新制度、新流程发布后自动更新对应Agent的知识上下文
- **行为模式学习**：根据高频操作习惯，Agent主动提供预判和建议
- **Skill插件化**：Agent能力以Skill插件形式开发，支持热插拔和独立迭代
- **行业规范同步**：自动跟踪国家标准、地方规范的更新，确保Agent建议符合最新法规

## 四、企业知识库

### 4.1 知识分类体系

| 知识类型 | 内容示例 | 来源 |
|---------|---------|------|
| 项目知识 | 项目方案、施工记录、验收报告、经验总结 | 项目交付过程沉淀 |
| 制度规范 | 公司管理制度、审批流程、岗位手册 | 管理层发布 |
| 行业知识 | 专项债政策文件、EPC行业标准、信息化规范 | 外部采集+内部整理 |
| 模板库 | 合同模板、标书模板、报告模板、公文模板 | 历史积累+持续优化 |
| 供应商库 | 供应商资质、历史合作评价、报价记录 | 采购部门维护 |
| 法规库 | 招投标法、政府采购法、建设工程管理条例、地方实施细则 | 法务部门维护+AI自动采集 |
| 审计案例库 | 历史审计发现、整改措施、典型问题清单 | 审计部门归档 |
| 造价指标库 | 历史项目造价指标、材料价格趋势、定额标准 | 造价部门维护+信息价采集 |

### 4.2 知识库核心能力

- **智能入库**：文档上传后自动提取摘要、打标签、建立与项目/部门的关联；支持PDF、Word、Excel、图片等多格式
- **语义检索**：支持自然语言提问，基于RAG架构实现精准检索，不仅匹配关键词更理解语义
- **知识推荐**：根据员工当前工作上下文（正在处理的项目/任务），主动推送相关知识
- **版本演进**：模板和制度文件支持版本管理，自动提示使用最新版本
- **权限隔离**：知识按密级和部门设置访问权限，确保信息安全
- **法规联动**：法规库更新时自动扫描在执行项目的影响面，推送合规提醒

## 五、核心业务场景

### 5.1 项目全生命周期管理

**场景覆盖**（对齐国内标准化流程）：

```
可研论证 → 立项审批 → 招投标 → 合同签订 → 财务评审
    → 设计管理 → 采购管理 → 施工/实施
    → 过程控制（四控：进度/质量/安全/成本）
    → 监理管理 → 阶段验收 → 竣工验收
    → 结算审计 → 决算审计 → 归档移交
```

| 项目阶段 | AI赋能要点 |
|---------|-----------|
| 可研论证 | 投标Agent自动监控招标网站，匹配公司资质后推送；可对话式生成项目可研报告初稿 |
| 立项审批 | 多Agent并行评估（法务风险+财务可行性+资源匹配），自动生成《立项评估综合报告》 |
| 招投标 | 自动拆解招标文件要求，生成投标书框架，AI评分预估中标概率，合规性自检 |
| 合同签订 | 法务Agent逐条审查，对比标准合同模板，标注风险条款并生成修改建议 |
| 财务评审 | 财务Agent协助概预算编制，自动核查定额套用、工程量计算准确性 |
| 施工/实施 | 项目管理Agent每日汇总进度偏差，自动生成项目周报；风险识别后触发预警工作流 |
| 过程控制 | 过控Agent实时监控四控指标，偏差超阈值自动预警，生成纠偏建议方案 |
| 监理管理 | 监理报告自动归档，旁站/巡视记录数字化，质量问题闭环跟踪 |
| 竣工验收 | 自动核查验收条件完备性，生成验收清单，组织验收流程推进 |
| 结算审计 | 财务Agent自动核对合同金额与实际支出，审计Agent辅助编制审计底稿 |
| 归档移交 | 知识Agent自动提取项目经验教训，结构化入库，竣工资料归档校验 |

### 5.2 国内项目标准化流程管理（重点新增）

#### 5.2.1 招投标全流程管理

```
招标公告发布/监控 → 资格预审 → 招标文件编制/获取
  → 投标文件编制 → 投标报价策略
  → 开标 → 评标 → 中标公示 → 签约
```

| 环节 | 功能要求 | AI赋能 |
|------|---------|--------|
| 招标监控 | 自动抓取全国公共资源交易中心、政府采购网招标信息 | 投标Agent按资质/地域/行业自动匹配并推送 |
| 资格预审 | 预审文件模板、资质材料自动归集 | 自动核查资质有效期、业绩匹配度 |
| 招标文件分析 | 招标文件结构化拆解、关键条款提取 | AI拆解评分标准，标注废标风险点 |
| 投标文件编制 | 技术方案、商务报价、资质材料三部分 | 从知识库调取类似项目方案，自动填充模板 |
| 报价策略 | 历史中标价分析、竞对分析 | 基于历史数据建议报价区间，预测中标概率 |
| 评标管理 | 评标记录、评审意见归档 | 自动生成评标汇总，标注异常报价 |
| 合规校验 | 全流程合规性自动校验 | 比对《招标投标法》《政府采购法》要求，标注违规风险 |

#### 5.2.2 财务评审（财评）管理

覆盖工程项目全周期四级财评：**概算评审 → 预算评审 → 结算评审 → 决算评审**

| 财评阶段 | 评审内容 | AI辅助能力 |
|---------|---------|-----------|
| 概算评审 | 投资估算合理性、建设规模适当性 | 对标同类项目指标，自动标注偏差项 |
| 预算评审 | 工程量清单核查、定额套用、取费标准 | 自动核算工程量、比对定额库、信息价校验 |
| 结算评审 | 实际完成量核实、变更签证核查、材料调差 | 对比合同/变更/实际量三方数据，标注差异 |
| 决算评审 | 项目总投资确认、资金使用合规性 | 汇总全项目财务数据，生成决算报告初稿 |

#### 5.2.3 过程控制（过控）管理

实施"四控"标准化管理：**进度控制、质量控制、安全控制、成本控制**

| 控制维度 | 管控要求 | 功能设计 |
|---------|---------|---------|
| **进度控制** | 里程碑节点管控、关键路径分析、工期预警 | 甘特图自动更新、实际vs计划偏差分析、延期原因追溯 |
| **质量控制** | 质量检验计划、隐蔽工程验收、质量问题台账 | 检验点自动提醒、问题闭环跟踪、质量评分统计 |
| **安全控制** | 安全检查清单、隐患排查、安全培训记录 | 安全巡检数字化、隐患整改闭环、安全日志自动归档 |
| **成本控制** | 成本预算执行监控、变更成本影响评估 | 实时成本对比预算、超支预警、变更对成本的影响分析 |

**偏差预警机制**：

| 预警级别 | 触发条件 | 响应机制 |
|---------|---------|---------|
| 黄色预警 | 偏差 5%~10% | 通知项目经理+生成纠偏建议 |
| 橙色预警 | 偏差 10%~20% | 通知部门负责人+启动专项分析 |
| 红色预警 | 偏差 > 20% | 通知管理层+暂停相关流程+要求纠偏方案审批 |

#### 5.2.4 监理管理

| 监理业务 | 功能要求 | 数字化支撑 |
|---------|---------|-----------|
| 旁站监理 | 关键工序旁站记录、影像留存 | 移动端表单+拍照上传+GPS定位 |
| 巡视检查 | 日常巡视记录、问题台账 | 巡视清单模板、问题自动录入台账 |
| 平行检验 | 独立检测记录、数据比对 | 检测数据录入、与施工方数据自动比对 |
| 监理报告 | 月报/周报/专题报告 | AI辅助生成报告框架、自动填充数据 |
| 工程变更 | 变更申请审核、影响评估 | 变更对四控指标的影响自动评估 |

#### 5.2.5 审计管理

覆盖**事前审计（预防）→ 事中审计（跟踪）→ 事后审计（结算/竣工）**

| 审计类型 | 审计重点 | AI辅助能力 |
|---------|---------|-----------|
| 跟踪审计 | 施工过程中的造价控制、变更签证、隐蔽工程 | 实时数据采集、异常交易标注、变更合规性校验 |
| 结算审计 | 工程量核实、价格核查、合同执行情况 | 自动比对工程量清单、定额核查、生成审计底稿 |
| 竣工审计 | 项目总投资、资金使用、建设程序合规 | 汇总全项目数据、合规性全面核查、出具审计报告初稿 |
| 内部审计 | 管理制度执行、内控有效性、风险管理 | 制度执行数据统计、偏差分析、整改跟踪 |

### 5.3 多Agent协作场景

**场景一：新项目启动评估**

```
员工发起"启动XX项目评估" →
  调度Agent并行分派：
    ├─ 法务Agent → 审查合同风险点 → 输出法律风险清单
    ├─ 财务Agent → 测算项目利润率 → 输出财务可行性分析
    ├─ 采购Agent → 评估关键材料供应情况 → 输出供应链风险评估
    ├─ 项目管理Agent → 评估团队资源 → 输出资源调配建议
    └─ 审计Agent → 合规性预审 → 输出合规风险清单
  调度Agent汇总 → 生成《项目启动评估综合报告》→ 推送给决策层审批
```

**场景二：工程变更联动处理**

```
项目经理发起"工程变更申请" →
  调度Agent串行处理：
    过控Agent → 评估变更对四控指标影响 → 输出影响评估报告
    → 财务Agent → 测算变更成本 → 输出费用调整方案
    → 法务Agent → 审查变更合同条款 → 输出法律意见
    → 审计Agent → 变更合规性校验 → 输出审计意见
  汇总生成《变更审批表》→ 推送审批流程
```

**场景三：月度过控分析**

```
过控Agent自动触发月度分析 →
  并行采集：
    ├─ 进度数据（实际 vs 计划）
    ├─ 质量数据（检验合格率、问题台账）
    ├─ 安全数据（巡检记录、隐患台账）
    └─ 成本数据（已发生 vs 预算）
  过控Agent → 生成《月度过控分析报告》→ 偏差项触发预警
  → 推送项目经理和管理层
```

## 八、非功能性需求

### 8.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| Agent响应时间 | 普通问答 < 3秒，复杂分析 < 15秒 | 含模型推理+知识库检索时间 |
| 并发用户数 | 支持200+用户同时在线 | 可根据业务增长水平扩容 |
| 知识检索 | 百万级文档检索 < 2秒 | 基于向量相似度计算 |
| 系统可用性 | 99.5%（工作时间段） | 非工作时间可安排维护窗口 |
| 可视化渲染 | 仪表盘加载 < 2秒，大图渲染 < 3秒 | 含数据查询+图表渲染 |
| 数据刷新 | 仪表盘数据 ≤ 5分钟延迟 | 预警类数据实时推送 |

### 8.2 安全与合规要求

- **数据加密**：全链路TLS 1.3加密，数据库字段级加密
- **数据合规**：符合《数据安全法》《个人信息保护法》要求，LLM推理数据不出境
- **审计日志**：操作日志全量记录，支持审计追溯，满足跟踪审计要求
- **数据脱敏**：敏感数据（合同金额、员工薪资等）脱敏后再进入LLM上下文
- **权限控制**：基于RBAC + ABAC的细粒度控制，确保数据最小必要访问
- **等保合规**：建议按等保三级标准设计，满足政府项目数据安全要求
- **电子签名**：关键审批支持电子签名，符合《电子签名法》要求

### 8.3 可扩展性

- **Agent Skill插件化**：Agent能力以Skill插件形式开发，支持热插拔
- **工作流自定义**：工作流模板支持可视化自定义，业务人员可自行配置
- **外部集成**：对接外部系统（OA、ERP、财务系统、公共资源交易平台）采用标准API网关
- **模型可替换**：支持多模型切换，不绑定单一LLM供应商
- **可视化扩展**：仪表盘组件支持自定义开发和第三方图表集成

### 8.4 部署方式

建议采用 **私有化部署** 方案（考虑到政府项目数据的敏感性），核心LLM模型通过本地GPU服务器运行（支持国产GPU如华为昇腾、海光AI），辅助能力可选择性接入国内云端API。

## 九、实施路线与交付计划

| 阶段 | 周期 | 核心交付物 | 优先级 |
|------|------|-----------|-------|
| **P0：基座搭建** | 8-10周 | 对话引擎、通用Agent、知识库基座、权限体系、基础UI框架（monday.com风格多视图） | 最高 |
| **P1：核心场景** | 8-10周 | 项目管理Agent、文档Agent、投标Agent、表格/看板/甘特图视图、工作流引擎、招投标全流程管理 | 高 |
| **P2：职能Agent与过控体系** | 8-10周 | 财务/法务/采购/人事/过控/审计Agent、跨部门工作流、可交互卡片体系、四控管理、财评管理、监理管理 | 中 |
| **P3：管理者鸟瞰** | 6-8周 | 项目群仪表盘、思维导图、流程全景图、风险雷达、资源热力图、经营分析看板 | 中 |

> **备注**：各阶段均采用敏捷开发模式，每2周一个Sprint，确保可持续交付与反馈迭代。P0阶段建议先在1-2个试点项目上运行，验证核心流程后再全面推广。

## 十、术语表

| 术语 | 说明 |
|------|------|
| Agent | 具备特定领域知识和技能的AI助手，能通过对话理解意图并执行操作 |
| Skill | Agent的原子能力单元，如"合同风险审查"是法务Agent的一个Skill |
| RAG | 检索增强生成（Retrieval-Augmented Generation），结合知识库检索与大模型生成，确保回答基于事实 |
| 工作流引擎 | 管理业务流程流转的核心组件，支持自动化审批和AI动态路由 |
| 可交互卡片 | 在对话中嵌入的富交互组件，支持按钮操作、表单填写、数据展示等 |
| EPC | 设计-采购-施工总承包模式（Engineering, Procurement, Construction） |
| 专项债 | 地方政府为有一定收益的公益性项目发行的债券 |
| LLM | 大语言模型（Large Language Model），Agent的推理核心 |
| Embedding | 将文本转换为向量表示的技术，用于语义检索 |
| 等保三级 | 信息安全等级保护三级，国内重要信息系统的安全标准 |
| 四控 | 项目管理中的四大控制维度：进度控制、质量控制、安全控制、成本控制 |
| 财评 | 财务评审，对工程项目概算/预算/结算/决算的官方评审程序 |
| 过控 | 过程控制，对项目执行过程中各维度指标的监控与管理 |
| WBS | 工作分解结构（Work Breakdown Structure），将项目分解为可管理的工作包 |
| S曲线 | 项目累计成本/进度随时间变化的曲线，用于偏差分析 |
| 跟踪审计 | 在工程建设过程中同步开展的审计活动，实现事中监督 |
