## 二、分批开发计划

### Sprint 1: 核心表单与交互（P0）

**目标**: 补齐两个模块最基本的创建/编辑流程

#### 1.1 任务创建 Drawer
- 新建 `frontend/src/components/tasks/TaskCreateDrawer.tsx`
- 右侧滑入Drawer + 半透明遮罩
- 表单字段: 任务名称(必填)、所属项目(下拉)、负责人(下拉)、优先级(下拉)、截止日期(date picker)、描述(textarea)
- 集成到 Tasks.tsx 和 ProjectDetail.tsx 的"新建任务"按钮
- 创建成功后 Toast 提示 + 列表自动刷新

#### 1.2 看板拖拽
- 使用 `@dnd-kit/core` + `@dnd-kit/sortable` 实现拖拽
- TaskKanban.tsx: 拖拽卡片到目标状态列 → 调用 updateTaskStatus
- 拖拽时视觉反馈(拖影+目标列高亮)
- 乐观更新 + 失败回滚

#### 1.3 任务筛选联动
- TaskFilters 状态变化时调用 store.fetchTasks()
- 支持组合筛选: 状态 + 优先级 + 项目
- 搜索框 debounce 300ms

#### 1.4 项目创建完整表单
- 改造 ProjectsDashboard.tsx 的创建表单为 Drawer
- 新建 `frontend/src/components/projects/ProjectCreateDrawer.tsx`
- 字段: 项目名称(必填)、项目类型(下拉)、预算金额、截止日期、项目阶段(默认立项)、负责人

#### 1.5 项目删除确认
- ProjectDetail header 添加删除按钮
- 确认弹窗: "确定删除项目「xxx」？此操作不可恢复"
- 删除后跳转到项目列表

### Sprint 2: 功能增强（P1）

#### 2.1 列表视图排序
- TaskList.tsx 列头添加排序图标(升/降)
- 前端排序: 按名称、状态、优先级、截止日期、负责人
- 排序状态存入 store

#### 2.2 任务按组分组
- UI 添加分组选择器: 无分组 / 按项目 / 按优先级 / 按截止日期
- TaskList 按分组渲染分隔标题 + 折叠/展开

#### 2.3 里程碑内联编辑
- 点击里程碑名称/日期/状态可内联编辑
- onBlur 自动保存 (PATCH /milestones/{id})

#### 2.4 风险内联编辑
- 点击风险描述/等级可编辑
- 添加缓解措施(mitigation)输入字段
- 添加负责人(owner)字段

#### 2.5 活动日志Tab
- ProjectDetail 添加"动态"Tab
- 调用 GET /api/projects/{id}/activities
- 时间线样式渲染活动事件

#### 2.6 任务详情-动态更新
- TaskDetailModal "更新"按钮 → 创建评论/动态

#### 2.7 逾期任务高亮
- 任务卡片/列表行: due_date < today && status !== 'done' → 红色边框

## 三、技术注意事项

1. **Drawer组件**: 复用 `components/daily/DrawerPanel.tsx` 的模式
2. **拖拽库**: `@dnd-kit/core` (已在项目依赖范围内适用)
3. **乐观更新**: CRUD操作先更新UI，失败后回滚
4. **Toast**: 使用现有 notificationStore
5. **保持控件化**: 新视图组件放在 `widgets/views/`，注册到 registry
6. **数据注入双模式**: 新控件支持 props.data ?? useStore() 模式
